# 003 · Single-page app

## Behavior
- React app served by the API: register, sign in, see the profile and the admin list (if admin), list and revoke sessions, sign out.
- The access token lives in memory. On `401` the app calls `/api/auth/refresh` once and retries; if that fails, it shows the sign-in form.
- On load, the app tries a silent refresh, so a page reload keeps the user signed in.
- The sessions list shows each device (user agent) and its last use; revoking one signs that device out at its next refresh.
- Reuse detection cannot be clicked from the page (the refresh cookie is not readable by JavaScript, by design); it is shown with `curl` in the README and covered by tests.

## Out of scope
Design system, routing library.
